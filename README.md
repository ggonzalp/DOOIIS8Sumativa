# SPEEDFAST

La actividad sumativa de esta semana consiste continuar desarrollando un sistema orientado 
a objetos que simula la conexión entre el programa y la interfaz gráfica con la base de datos.


## Descripción

SpeedFast registra pedidos de comida, encomiendas y express, cada uno con su prioridad y su estado,
y los asigna a un repartidor para su entrega. Esta semana el sistema resuelve la lógica de negocio completa
con operaciones CRUD que permitan gestionar repartidores, pedidos y entregas de manera persistente. 
 

## Ejecución

1° Clonar el repositorio: https://github.com/ggonzalp/DOOIIS7Formativa.git

2° Abrir el proyecto en IntelliJ IDEA

3° Ejecutar la clase principal: src/ui/Main.java

4° El programa cargará automáticamente los datos ingresados ​​de forma local y manual.
